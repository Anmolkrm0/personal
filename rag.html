What each stage is actually doing
Use this as your mental model when explaining RAG in an interview.
Chunking

Break large documents into retrievable units. The goal is useful context, not arbitrary splitting.

Embedding

Convert text into a numerical representation where semantically similar text tends to be close together.

Retrieval

Embed the user query and search the vector database for the most similar chunks.

Reranking

Re-score the retrieved candidates using a stronger relevance model before giving context to the LLM.

Important distinction: Vector search finds candidate chunks. Reranking improves their order. The LLM then uses the selected context to generate the response. Retrieval and generation are separate jobs.
